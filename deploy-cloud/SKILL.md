# 云函数部署指引

## 触发条件

- 用户输入 `/deploy-cloud` 后跟云函数名，如 `/deploy-cloud arabicTts`
- 用户问"怎么上传云函数""部署之后没生效"等
- 改完云函数代码后自动触发给出部署步骤

## 背景

Claude 只能编辑云函数代码（`cloudfunctions/<name>/index.js`），无法在微信开发者工具里执行上传操作。所以部署必须由用户在微信开发者工具里手动完成。

## 部署云函数（标准流程）

### 方法一：右键上传（推荐，最简单）

1. 打开**微信开发者工具**
2. 左侧文件树找到 `cloudfunctions/<云函数名>`
3. 右键该文件夹 → **「上传并部署：云端安装依赖」**
4. 等待上传完成（底部状态栏会显示进度）
5. 上传成功后，状态栏提示绿色 ✓

### 方法二：批量上传（多个云函数都改了）

1. 在 `cloudfunctions/` 目录下，对每个改过的文件夹重复方法一
2. 没有快捷批量上传，必须逐个右键

### 验证部署是否生效

1. 在微信开发者工具顶部点「云开发」按钮
2. 左侧菜单选「云函数」
3. 找到刚部署的函数 → 查看**最近调用**日志
4. 可以点「测试」输入测试参数跑一次确认

## 云函数环境变量配置

如果改过的云函数需要环境变量（如 `arabicTts` 需要 `TENCENT_SECRET_ID` 等），部署后还要配：

1. 微信开发者工具 →「云开发」→「云函数」
2. 点击目标函数名 →「配置」
3. 在「环境变量」tab 添加键值对，如：
   | 变量名 | 值 |
   |--------|-----|
   | `TENCENT_SECRET_ID` | `AKIDxxxxxxxx` |
   | `TENCENT_SECRET_KEY` | `xxxxxxxx` |
   | `TENCENT_TTS_VOICE_ID` | `eefr2kkN0KbwXw30DihbHXNkdZAQlXBNH1wuEyNIi30lE0KxayXot6` |
4. 保存后云函数下次调用时自动读取

## 常见问题

### 上传后云函数没反应？
- 检查云函数日志（云开发 → 云函数 → 日志），看有没有报错
- 常见：环境变量没配、npm 依赖没装上、权限不足

### 提示"上传失败"？
- 网络问题：重试 1-2 次
- 如果一直失败：先右键 →「在终端中打开」→ 手动 `npm install` → 再右键 →「上传（仅上传不安装依赖）」

### 云函数调用次数超限？
- 去腾讯云控制台看配额
- 免费额度：每月 10 万次调用，一般够用

## 当前项目云函数清单

| 云函数 | 用途 | 是否需要环境变量 |
|--------|------|:--:|
| `arabicTts` | 阿语 TTS 语音合成 | ✅ SECRET_ID/KEY/VOICE_ID |
| `contentImporter` | 管理员导入内容资源 | ✅ ADMIN_OPENIDS |
| `ai-dialogue` | AI 自由对话 | 视配置而定 |

## 不要做

- ❌ 不要建议用户手动编辑云函数在线代码——所有代码改动用 Claude + 本地文件，然后部署
- ❌ 不要让用户跑 `tcb` CLI 命令——太复杂，用 GUI 右键上传即可
- ❌ 不要在代码里硬编码密钥——环境变量才是安全做法
